# 🛒 Lista de Produtos — Simulação de Carrinho de Compras

Projeto desenvolvido com o objetivo de **praticar JavaScript moderno (ES6+)**, aplicando **boas práticas de código, manipulação do DOM e organização funcional**.  
A aplicação simula um **carrinho de compras interativo**, permitindo ao usuário adicionar, remover e visualizar produtos com atualização automática do valor total.

---

## 🎯 Objetivo do Projeto

Demonstrar o domínio de **JavaScript puro**, **eventos dinâmicos** e **estrutura lógica de um e-commerce** em uma interface simples e funcional, sem dependências externas de frameworks.

Durante o desenvolvimento, foram aplicados:
- Boas práticas de **organização de código** e **componentização lógica**.  
- Uso eficiente de **event listeners** e **atualizações em tempo real do DOM**.  
- Padronização com ferramentas de linting e formatação automática.  
- Estrutura modular e legível, seguindo princípios de código limpo.

---

## ⚙️ Funcionalidades

✅ Adicionar produtos ao carrinho  
✅ Remover produtos individualmente  
✅ Exibir lista completa de produtos  
✅ Atualização em tempo real do valor total da compra  
✅ Interface simples e responsiva  
✅ Feedback visual ao adicionar ou remover itens  

---

## 🧠 Conceitos Aplicados

- Manipulação do DOM com **JavaScript puro**
- Controle de estado do carrinho
- Atualizações dinâmicas sem recarregar a página
- Uso de **arrow functions**, **template literals** e **métodos de array**
- **Boas práticas de organização** e **uso de padrões de projeto simples**

---

## 🧩 Tecnologias Utilizadas

- **HTML5**  
- **CSS3**  
- **JavaScript (ES6+)**  
- **Node.js** – ambiente de execução  
- **ESLint** & **Prettier** – padronização e qualidade de código
